# Perfil profissional

Copie `perfil_base.exemplo.json` para `perfil_base.json` e preencha seus dados
localmente. O arquivo pessoal é ignorado pelo Git e não deve ser compartilhado
no repositório. Não inclua dados reais no arquivo de exemplo.

Copie `contatos_diretos.exemplo.csv` para `contatos_diretos.csv` antes de
adicionar contatos reais. O arquivo pessoal também é ignorado pelo Git. Nunca
adicione credenciais, currículos ou bancos de dados ao repositório.

Arquivos ignorados que já foram rastreados precisam ser removidos do índice do
Git; a regra não apaga dados que já estejam no histórico ou em cópias públicas.
